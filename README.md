Entry for the make.fun bounty "Sum up 26 November's world news in one image" ($100, ends 28 November 2026).

The program copies the front-page image `entry.png` to the output directory as `entry.png`. The image is a newspaper front page for Thursday 26 November 2026: a fuel tanker fire kills 31 on a Cairo highway, Trump proposes tariffs on 14 trading partners including Indonesia, Israeli judges urge dropping Netanyahu's bribery case, Poland plans a no-fly zone near Ukraine, North Korea expels Switzerland's top diplomat, and Colombian forces rescue 76 hostages from a supermarket siege.

## Run it

```sh
node main.ts
```

Outside the grader, `MAKEFUN_OUTPUT_DIR` stands in for `/output`:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
